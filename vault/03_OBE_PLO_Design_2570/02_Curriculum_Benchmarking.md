# Curriculum Benchmarking
## หลักสูตรประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) สาขาวิชาพืชศาสตร์

> [!abstract] วัตถุประสงค์
> เปรียบเทียบหลักสูตรด้านพืชศาสตร์และการผลิตพืช รวมทั้งแนวโน้มการจัดการศึกษาด้านการเกษตร เพื่อใช้ประกอบการกำหนด PLO โครงสร้างหลักสูตร รายวิชา และรูปแบบการเรียนรู้ของมหาวิทยาลัยกาฬสินธุ์

## 1. กรอบการ Benchmark

| มิติ | ประเด็นเปรียบเทียบ |
|---|---|
| Curriculum Structure | หน่วยกิต กลุ่มวิชาชีพ ฝึกงาน/ทวิภาคี และโครงงาน |
| Professional Competencies | การผลิตพืช ดิน น้ำ ศัตรูพืช เครื่องจักร และหลังการเก็บเกี่ยว |
| Future Skills | Digital/Smart/Precision Agriculture, Data, AI/IoT, Sustainability และ Entrepreneurship |
| Learning Experience | Hands-on, Problem/Project/Work-based Learning และสถานการณ์จริง |

## 3. Direct Benchmark: มทร.ล้านนา

หลักสูตร ปวส. พืชศาสตร์ของ มทร.ล้านนา (ข้อมูลปีการศึกษา 2565) ใช้เวลาเรียนปกติ 2 ปี และมี 84 หน่วยกิต

| องค์ประกอบ | หน่วยกิต |
|---|---:|
| หมวดสมรรถนะแกนกลาง | 21 |
| หมวดสมรรถนะวิชาชีพ | 57 |
| วิชาเลือกเสรี | 6 |
| **รวม** | **84** |

หมวดสมรรถนะวิชาชีพประกอบด้วยพื้นฐาน 15 หน่วยกิต เฉพาะ 22 หน่วยกิต เลือก 12 หน่วยกิต ฝึกประสบการณ์ 4 หน่วยกิต และโครงงาน 4 หน่วยกิต รายวิชาที่สะท้อนทิศทางสำคัญ ได้แก่ ทักษะช่างเกษตรและเครื่องทุ่นแรงฟาร์ม คอมพิวเตอร์และเทคโนโลยีสารสนเทศเพื่อการเกษตร การจัดการธุรกิจเกษตรและการตลาดดิจิทัล ภูมิอากาศพืชและการจัดการน้ำ ดินและธาตุอาหาร ศัตรูพืช หลังการเก็บเกี่ยว ฟาร์มพืชอัจฉริยะ และอากาศยานไร้คนขับทางการเกษตร

> [!note] ข้อค้นพบ
> หลักสูตร Direct Benchmark วางทักษะปฏิบัติ เครื่องมือ เทคโนโลยี ฝึกงาน และโครงงานไว้ในโครงสร้างอย่างชัดเจน

## 4. National/Vocational Benchmark

หลักสูตร ปวส. พ.ศ. 2567 ของ สอศ. จัดสาขาพืชศาสตร์ (31702) ไว้ในประเภทวิชาเกษตรกรรมและประมง กลุ่มอาชีพการผลิตพืช ส่วนวิทยาลัยเกษตรและเทคโนโลยีราชบุรีเปิดสอน ปวส. พืชศาสตร์ โดยเผยแพร่การเรียนทั้งทฤษฎีและปฏิบัติ เช่น พืชไร่ พืชผัก ไม้ผล ไม้ดอก เห็ด เพาะเลี้ยงเนื้อเยื่อ สารชีวภาพ ปุ๋ยหมัก และพืชสมุนไพร พร้อมงานฟาร์มและการเชื่อมโยงทวิภาคี

## 5. ทิศทางการเปลี่ยนแปลง

**Traditional:** สอนศาสตร์ย่อยแยกกัน เช่น พืชไร่ พืชสวน ดิน โรคพืช แมลง วัชพืช และการขยายพันธุ์

**Emerging Competency Model:** การผลิตพืช → จัดการทรัพยากร → เทคโนโลยีและข้อมูล → แก้ปัญหา → คุณภาพและมาตรฐาน → ธุรกิจและตลาด → ความยั่งยืน

> [!important] ข้อเสนอ
> เปลี่ยนจาก Subject-based Plant Science ไปสู่ Competency-based Plant Production โดยคงพื้นฐานวิชาการที่จำเป็นและบูรณาการกับภาระงานจริง

## 7. Gap Analysis และทิศทางพัฒนา

### สิ่งที่ควรรักษา

- การผลิตพืชเชิงปฏิบัติเป็น Core Competency
- บูรณาการ Soil–Water–Plant–Pest กับแปลงจริง
- ฝึกงาน ทวิภาคี โครงงาน และโจทย์จากสถานประกอบการ

### สิ่งที่ควรเพิ่มความเด่น

- **Digital + Data + Smart Agriculture:** เลือกใช้ → ใช้งาน → เก็บข้อมูล → แปลผล → ตัดสินใจ โดยไม่กำหนดให้ผู้เรียนต้องพัฒนา AI/IoT ขั้นสูง
- **Production + Business + Market:** ผลิต → คุณภาพ/ผลผลิต → ต้นทุน → ตลาด → รายได้
- **Authentic Assessment:** ประเมินจากภาระงาน ผลงาน และสถานการณ์ปฏิบัติจริง

## 10. Positioning ที่เสนอ

> [!quote] Proposed Program Positioning
> **หลักสูตรพืชศาสตร์เชิงปฏิบัติที่มุ่งพัฒนาผู้เรียนให้สามารถจัดการการผลิตพืชได้ตลอดกระบวนการ ใช้เครื่องมือ เทคโนโลยีดิจิทัลและข้อมูลในการตัดสินใจ แก้ปัญหาตามบริบทพื้นที่ และเชื่อมโยงการผลิตกับธุรกิจและตลาดอย่างรับผิดชอบและยั่งยืน**

## 11. Curriculum Design Direction

การผลิตพืช → ดิน + น้ำ + ธาตุอาหาร + ศัตรูพืช → เครื่องมือ/เครื่องจักร → ดิจิทัล/ข้อมูล → แก้ปัญหา → คุณภาพ/มาตรฐาน → หลังการเก็บเกี่ยว → ต้นทุน/ตลาด/ธุรกิจ → สถานประกอบการและชุมชน

หลักสูตรจึงควรออกแบบให้รายวิชาทำงานร่วมกันเพื่อพัฒนาสมรรถนะการจัดการการผลิตพืชตลอดกระบวนการ ไม่ใช่เพียงรวมรายวิชาทางพืชศาสตร์เข้าด้วยกัน

## 12. ข้อเสนอสำหรับการปรับหลักสูตร

| ประเด็น | แนวทางพัฒนา |
|---|---|
| การผลิตพืช | กำหนดเป็น Core Competency |
| ดิน–น้ำ–ศัตรูพืช | บูรณาการกับสถานการณ์จริง |
| เครื่องมือ/เครื่องจักร | เพิ่มการฝึกใช้งานจริง |
| Digital Agriculture/Data | บูรณาการในรายวิชาชีพและใช้ข้อมูลจริง |
| Smart Farming/AI | เน้นใช้งานและตัดสินใจ ไม่เน้นพัฒนาระบบขั้นสูง |
| Business | เชื่อมต้นทุน ตลาด การผลิต และการทดลองจำหน่าย |
| Sustainability | บูรณาการมาตรฐาน ความปลอดภัย ทรัพยากร และสิ่งแวดล้อม |
| Field/Dual Experience | ใช้แปลง สถานประกอบการ และ competency จากงานจริง |
| Assessment | เพิ่ม Performance/Authentic Assessment |

## 13. สรุป

หลักสูตรควรรักษาความเข้มแข็งด้านการผลิตพืชและทักษะปฏิบัติ พร้อมเพิ่มเทคโนโลยีดิจิทัล การใช้ข้อมูล การแก้ปัญหา ธุรกิจ ตลาด และการเรียนรู้จากสถานการณ์จริง เพื่อพัฒนาจาก “ผู้มีความรู้ด้านพืชศาสตร์” เป็น “ผู้ปฏิบัติงานที่จัดการการผลิต ใช้เทคโนโลยี แก้ปัญหา และเชื่อมโยงการผลิตกับอาชีพและตลาดได้จริง”
