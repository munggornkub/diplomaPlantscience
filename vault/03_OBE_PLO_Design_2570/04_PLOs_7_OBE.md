# ผลลัพธ์การเรียนรู้ระดับหลักสูตร (PLO)

> [!warning] จำนวน PLO
> ชื่อไฟล์เดิมระบุ `PLOs_7` แต่เอกสารหลักสูตรฉบับนี้กำหนด PLO จริง **6 ข้อ** จึงใช้ข้อมูล 6 ข้อตามต้นฉบับ และคงชื่อไฟล์เดิมไว้เพื่อไม่ให้ลิงก์ Obsidian เดิมเสีย

## PLO ทั้ง 6 ข้อ

| รหัส | ผลลัพธ์การเรียนรู้ระดับหลักสูตร |
|---|---|
| PLO1 | ปฏิบัติงานด้านพืชศาสตร์ตามมาตรฐานวิชาชีพ โดยยึดมั่นคุณธรรม จริยธรรม จรรยาบรรณวิชาชีพ ความปลอดภัยในการปฏิบัติงาน และความรับผิดชอบต่อสังคมและสิ่งแวดล้อม |
| PLO2 | ใช้ความรู้และหลักการด้านพืชศาสตร์ในการผลิตพืช การจัดการแปลงผลิต และการจัดการศัตรูพืชได้ตามมาตรฐานวิชาชีพ |
| PLO3 | เลือกใช้เครื่องมือ เทคโนโลยีดิจิทัล และข้อมูล เพื่อสนับสนุนการผลิตพืชและการจัดการฟาร์มได้อย่างเหมาะสมกับลักษณะงานและพื้นที่ |
| PLO4 | วิเคราะห์ปัญหาและเลือกแนวทางแก้ไขในการผลิตพืชโดยใช้หลักวิชาการ เทคโนโลยี และข้อมูลที่เหมาะสมกับบริบทของชุมชนหรือสถานประกอบการ |
| PLO5 | วางแผนและดำเนินงานด้านการผลิตพืชหรือธุรกิจเกษตรขนาดย่อม โดยคำนึงถึงต้นทุน ตลาด และการใช้ทรัพยากรอย่างเหมาะสม |
| PLO6 | สื่อสาร ประสานงาน และปฏิบัติงานร่วมกับชุมชน สถานประกอบการ และเครือข่ายวิชาชีพ โดยสอดคล้องกับวัฒนธรรมองค์กรและบริบทชุมชน |

## YLO และความเชื่อมโยงกับ PLO

สัญลักษณ์ ● หมายถึงความเชื่อมโยงหลัก และ ○ หมายถึงความเชื่อมโยงสนับสนุน

| รหัส | ผลลัพธ์การเรียนรู้รายปี | หลัก | สนับสนุน |
|---|---|---|---|
| YLO1.1 | ปฏิบัติงานพื้นฐานด้านการผลิตพืช การจัดการแปลง และการจัดการศัตรูพืช โดยใช้เครื่องมือและเทคโนโลยีที่เหมาะสม ตามขั้นตอน มาตรฐานวิชาชีพ และหลักความปลอดภัย | PLO2 | PLO1, PLO3 |
| YLO1.2 | แก้ไขปัญหาเบื้องต้นในการปฏิบัติงานด้านพืชศาสตร์และสื่อสารประสานงานกับผู้อื่น โดยปฏิบัติงานด้วยความรับผิดชอบ มีคุณธรรม จริยธรรม และคำนึงถึงสังคมและสิ่งแวดล้อม | PLO1, PLO4, PLO6 | PLO2 |
| YLO2.1 | ปฏิบัติงานด้านการผลิตพืชและการจัดการฟาร์ม โดยเลือกใช้เครื่องมือ เทคโนโลยีดิจิทัล และข้อมูลที่เหมาะสมกับลักษณะงานและพื้นที่ได้ตามมาตรฐานวิชาชีพ | PLO2, PLO3 | PLO1, PLO4, PLO5 |
| YLO2.2 | วิเคราะห์ปัญหา เลือกแนวทางแก้ไข และวางแผนดำเนินงานด้านการผลิตพืชหรือธุรกิจเกษตรขนาดย่อม พร้อมสื่อสารและทำงานร่วมกับชุมชน สถานประกอบการ และเครือข่ายวิชาชีพได้ตามบริบท | PLO4, PLO5, PLO6 | PLO1, PLO2, PLO3 |

## ภาพรวมกลยุทธ์การสอนและประเมินผล

| PLO | กลยุทธ์การสอนหลัก | การประเมินหลัก |
|---|---|---|
| PLO1 | Work-based Learning, Practice-based Learning, สถานการณ์จำลองด้านจริยธรรมและความปลอดภัย | Rubric/Checklist การปฏิบัติงาน การสังเกตพฤติกรรม และผลประเมินจากสถานประกอบการ |
| PLO2 | Practice-based Learning, Learning by Doing และโจทย์จากแปลงผลิตจริง | แบบทดสอบ Performance Assessment ผลผลิต ชิ้นงาน และบันทึกปฏิบัติงาน |
| PLO3 | Technology-enhanced Learning และ Problem/Task-based Learning | โจทย์เลือกเทคโนโลยี การปฏิบัติจริง และชิ้นงานหรือข้อมูลดิจิทัล |
| PLO4 | Problem-based Learning, Case-based Learning และการเรียนรู้จากพื้นที่จริง | Case/Problem-based Assessment รายงาน การนำเสนอ และ Rubric กระบวนการคิด |
| PLO5 | Project-based Learning และ Entrepreneurial Learning | แผนผลิตหรือแผนธุรกิจ การดำเนินงานจริง โครงการปลายภาค และ Portfolio |
| PLO6 | Collaborative Learning และ Community/Work-based Learning | Rubric การสื่อสารและทีม Peer Assessment และข้อมูลสะท้อนกลับจากชุมชนหรือสถานประกอบการ |
