# 30905*0002 ช่างเกษตรเบื้องต้น

> [!source] แหล่งข้อมูล

30905*0002 ช่างเกษตรเบื้องต้น       1-3-2 
    Basic Farm Mechanics     
อ้างอิงมาตรฐาน  
 - 
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบาย หลักการ  กระบวนการ  และความปลอดภัยในงานช่างเกษตรเบื้องต้น  ได้ถูกต้องตามหลัก
วิชาการ 
2. เลือกใช้และบำรุงรักษา วัสดุ อุปกรณ์ และเครื่องมืองานช่างเกษตร ได้เหมาะสมกับลักษณะงานและ
เป็นไปตามหลักความปลอดภัย 
3. ปฏิบัติงานเชื่อมโลหะเบื้องต้น ได้ถูกต้องตามขั้นตอนและข้อกำหนดด้านความปลอดภัย 
4. ปฏิบัติงานปูนและคอนกรีตเบื้องต้น ได้ถูกต้องตามขั้นตอนและข้อกำหนดของงาน 
5. ปฏิบัติงานไฟฟ้าเบื้องต้น ได้ถูกต้องตามขั้นตอนและข้อกำหนดด้านความปลอดภัย 
6. ปฏิบัติงานประปาเบื้องต้น ได้ถูกต้องตามขั้นตอนและข้อกำหนดของงาน 
7. ใช้และบำรุงรักษาเครื่องยนต์เล็กทางการเกษตร ได้ถูกต้องตามคู่มือและหลักความปลอดภัย 
8. ประยุกต์ใช้ทักษะงานช่างเกษตรในการแก้ปัญหางานพื้นฐาน  ได้เหมาะสมกับสถานการณ์  โดยใช้
ทรัพยากรอย่างคุ้มค่าและคำนึงถึงสิ่งแวดล้อม 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจหลักการ กระบวนการ เครื่องมือ วัสดุ อุปกรณ์ และความปลอดภัยในงานช่างเกษตรเบื้องต้น 
2. เลือกใช้และบำรุงรักษาเครื่องมือ  วัสดุ และอุปกรณ์  รวมทั้งปฏิบัติงานช่างเกษตรพื้นฐานได้ตาม
หลักการและขั้นตอน 
3. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงาน  มีความสนใจใฝ่รู้  ซื่อสัตย์  ขยัน อดทน มีวินัย  และ
รับผิดชอบต่องานช่างเกษตร 
4. ประยุกต์ใช้ความรู้และทักษะงานช่างเกษตรในการปฏิบัติงาน  โดยคำนึงถึงความปลอดภัย  การใช้
ทรัพยากรอย่างคุ้มค่า  และผลกระทบต่อสิ่งแวดล้อม 4. สามารถในการประยุกต์ใช้และความ
รับผิดชอบในงานช่างเกษตร  
สมรรถนะรายวิชา 
1. เตรียมและดำเนินงานช่างเกษตรเบื้องต้น  โดยเลือกใช้วัสดุ  อุปกรณ์ และเครื่องมือให้เหมาะสมกับ
ลักษณะงาน 
2. ปฏิบัติงานเชื่อมโลหะ  งานปูนและคอนกรีต  งานไฟฟ้า  และงานประปาเบื้องต้นตามหลักการและ
ขั้นตอนของงาน 
3. ใช้และบำรุงรักษาเครื่องยนต์เล็กและอุปกรณ์ทางการเกษตรตามคู่มือและหลักการบำรุงรักษา 
4. ปฏิบัติงานช่างเกษตรด้วยความรับผิดชอบและปลอดภัย  โดยคำนึงถึงการใช้ทรัพยากรอย่างคุ้มค่า
และการอนุรักษ์สิ่งแวดล้อม 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับความสำคัญ  หลักการ และความปลอดภัยในงานช่างเกษตร  วัสดุ อุปกรณ์ 
และเครื่องมืองานช่างเกษตร  การเลือกใช้และบำรุงรักษาเครื่องมือ  การปฏิบัติงานเชื่อมโลหะ  งานปูนและ
คอนกรีต งานไฟฟ้า และงานประปาเบื้องต้น การใช้และบำรุงรักษาเครื่องยนต์เล็กทางการเกษตร รวมทั้งการ
ประยุกต์ใช้ทักษะงานช่างเกษตร  โดยคำนึงถึงความปลอดภัย  การใช้ทรัพยากรอย่างคุ้มค่า  และการอนุรักษ์
สิ่งแวดล้อม
