# 30905*0005 อุตสาหกรรมเกษตรเบื้องต้น

> [!source] แหล่งข้อมูล

30905*0005 อุตสาหกรรมเกษตรเบื้องต้น               2-0-2  
 Introduction to Agro-Industry   
อ้างอิงมาตรฐาน  
 - 
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบายระบบและกระบวนการดำเนินงานอุตสาหกรรมเกษตรเบื้องต้นได้ 
2. วางแผน การดำเนินงานอุตสาหกรรมเกษตรเบื้องต้น ได้อย่างเป็นระบบและสอดคล้องกับเงื่อนไขที่กำหนด 
3. เลือก แนวทางการแปรรูป การบรรจุภัณฑ์ และการควบคุมคุณภาพผลิตภัณฑ์เกษตร ได้เหมาะสมกับประเภท
ผลิตภัณฑ์และมาตรฐานที่เกี่ยวข้อง 
4. เสนอแนวทาง  การขนส่งและจำหน่ายผลิตภัณฑ์เกษตร  ได้สอดคล้องกับลักษณะผลิตภัณฑ์และหลั กความ
ปลอดภัย 
จุดประสงค์รายวิชา  เพื่อให้  
 1. เข้าใจหลักการเกี่ยวกับงานอุตสาหกรรมเกษตรเบื้องต้น  และขั้นตอนการดำเนินงานอุตสาหกรรมเกษตร  
อย่างมีระบบและมาตรฐาน  
 2. สามารถวางแผนการดำเนินงานอุตสาหกรรมเบื้องต้นตามหลักการและกระบวนการ  
 3. มีเจตคติและกิจนิสัยที่ดีในการทำงาน  มีความรับผิดชอบ  รอบคอบ มีวินัย  ขยัน อดทน ประหยัด  และ
สามารถทำงานร่วมกับผู้อื่น  
 4. สามารถประยุกต์ใช้หลักการดำเนินงานอุตสาหกรรมเกษตรในการปฏิบัติงานอาชีพ  
สมรรถนะรายวิชา 
1. วางแผนการดำเนินงานอุตสาหกรรมเกษตรเบื้องต้นอย่างเป็นระบบ โดยคำนึงถึงคุณภาพ ความปลอดภัย และ
มาตรฐานที่เกี่ยวข้อง 
2. ประยุกต์ใช้หลักการแปรรูป บรรจุภัณฑ์ ควบคุมคุณภาพ ขนส่ง และจำหน่าย เพื่อกำหนดแนวทางดำเนินงาน
ที่เหมาะสมกับผลิตภัณฑ์เกษตร 
3. ปฏิบัติงานที่ได้รับมอบหมายด้วยความรับผิดชอบ รอบคอบ มีวินัย และทำงานร่วมกับผู้อื่น 
4. ความปลอดภัย 
คำอธิบายรายวิชา   
 ศึกษาเกี่ยวกับความสำคัญ ประโยชน์ และประเภทของอุตสาหกรรมเกษตร ระบบและการวางแผนดำเนินงาน
อุตสาหกรรมเกษตร  หลักการแปรรูปผลิตภัณฑ์  การบรรจุภัณฑ์  การควบคุมคุณภาพ  การขนส่ง  และการจำหน่าย  
ตลอดจนความปลอดภัยและมาตรฐานโรงงานอุตสาหกรรมเกษตร
