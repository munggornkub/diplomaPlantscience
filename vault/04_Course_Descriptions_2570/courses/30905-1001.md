# 30905*1001 การเป็นผู้ประกอบการ

> [!source] แหล่งข้อมูล

30905*1001  การเป็นผู้ประกอบการ                 2-2-3  
Entrepreneurship  
อ้างอิงมาตรฐาน 
 -  
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. วิเคราะห์ตนเอง โอกาสทางธุรกิจ ความต้องการของลูกค้า และบริบทตลาด เพื่อพัฒนาแนวคิดธุรกิจ 
2. วางแผนการจัดตั้งธุรกิจโดยกำหนดรูปแบบธุรกิจ แหล่งเงินทุน และแนวทางบริหารความเสี่ยงที่
เหมาะสม 
3. วิเคราะห์ต้นทุน ราคา รายรับ รายจ่าย และจุดคุ้มทุน เพื่อประกอบการวางแผนธุรกิจ 
4. จัดทำแผนธุรกิจหรือแบบจำลองธุรกิจ โดยประยุกต์ใช้การตลาดและเทคโนโลยีดิจิทัลอย่างเหมาะสม 
5. นำเสนอแนวคิดหรือแผนธุรกิจโดยคำนึงถึงกฎหมาย จริยธรรม และจรรยาบรรณในการประกอบธุรกิจ 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจหลักการเขียนแผนธุรกิจ การจัดตั้งธุรกิจและการเป็นผู้ประกอบการ  
2. มีทักษะในการเขียนแผนธุรกิจ การวางแผนจัดตั้งธุรกิจและการเป็นผู้ประกอบการ  
3. มีจรรยาบรรณและคุณสมบัติของผู้ประกอบธุรกิจ  
4. มีความสามารถประยุกต์ความรู้สู่การเป็นผู้ประกอบการธุรกิจดิจิทัล  
สมรรถนะรายวิชา   
1. พัฒนาแนวคิดและวางแผนการจัดตั้งธุรกิจโดยพิจารณาตนเอง โอกาสทางธุรกิจ ความต้องการของลูกค้า 
และบริบทตลาด 
2. จัดทำแผนธุรกิจหรือแบบจำลองธุรกิจโดยประยุกต์ใช้หลักการด้านการเงิน การตลาด การบริหารความ
เสี่ยง และเทคโนโลยีดิจิทัล 
3. ประยุกต์ใช้แนวคิดการเป็นผู้ประกอบการในการประกอบอาชีพ โดยคำนึงถึงกฎหมาย จริยธรรม และ
จรรยาบรรณในการประกอบธุรกิจ   
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับแนวคิดและคุณลักษณะของผู้ประกอบการ การวิเคราะห์ตนเองและโอกาสทางธุรกิจ 
การพัฒนาแนวคิดธุรกิจจากความต้องการของลูกค้าและบริบทตลาด การกำหนดรูปแบบธุรกิจ การวิเคราะห์ต้นทุน 
การกำหนดราคา รายรับ รายจ่าย และจุดคุ้มทุน การจัดหาแหล่งเงินทุน การต ลาดและการตลาดดิจิทัล การบริหาร
ความเสี่ยง กฎหมายและจริยธรรมที่เกี่ยวข้องกับการประกอบธุรกิจ การจัดทำแผนธุรกิจหรือแบบจำลองธุรกิจ และ
การนำเสนอแนวคิดธุรกิจเพื่อประยุกต์ใช้ในการประกอบอาชีพ
