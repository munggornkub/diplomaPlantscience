# 30905*1006 สรีรวิทยาของพืช

> [!source] แหล่งข้อมูล

30905*1006 สรีรวิทยาของพืช                 2-2-3  
Plant Physiology 
อ้างอิงมาตรฐาน  
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบายกระบวนการทางสรีรวิทยาของพืชและปัจจัยที่มีผลต่อการเจริญเติบโตและการให้ผลผลิต 
2. วิเคราะห์ความสัมพันธ์ระหว่างกระบวนการทางสรีรวิทยากับการเจริญเติบโตและการให้ผลผลิตของพืช 
3. วิเคราะห์ผลของปัจจัยที่เกี่ยวข้องต่อกระบวนการทางสรีรวิทยาและการเจริญเติบโตของพืช 
4. ใช้ความรู้ทางสรีรวิทยาของพืชในการวางแผนการผลิตและปรับปรุงผลผลิตพืช 
จุดประสงค์รายวิชา  เพื่อให้    
1. เข้าใจหลักการและกระบวนการทางสรีรวิทยาของพืช และปัจจัยที่มีผลต่อการเจริญเติบโตและการให้ผล
ผลิต 
2. สามารถวิเคราะห์ความสัมพันธ์ระหว่างกระบวนการทางสรีรวิทยากับการเจริญเติบโตและการให้ผลผลิต
ของพืช 
3. สามารถประยุกต์ใช้ความรู้ทางสรีรวิทยาของพืชในการผลิตและปรับปรุงผลผลิตพืช 
4. มีเจตคติและกิจนิสัยที่ดีในการศึกษาและปฏิบัติงาน มีความรับผิดชอบ สนใจใฝ่รู้ มีวินัย ซื่อสัตย์ ขยัน 
อดทน และมีความคิดริเริ่มสร้างสรรค์ 
สมรรถนะรายวิชา 
1. วิเคราะห์ความสัมพันธ์ระหว่างกระบวนการทางสรีรวิทยา ปัจจัยที่เกี่ยวข้อง การเจริญเติบโต และการ
ให้ผลผลิตของพืช 
2. ประยุกต์ใช้หลักสรีรวิทยาของพืชในการวางแผนการผลิตและปรับปรุงผลผลิตพืช 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับ ความสำคัญของกระบวนการทางสรีรวิทยาต่อการผลิตพืช ปัจจัยที่มีผลต่อการ
เจริญเติบโตและการให้ผลผลิตของพืช กระบวนการสังเคราะห์แสง การหายใจ การคายน้ำ การลำเลียง การ
เจริญเติบโต การออกดอก การติดผลและการสุกแก่ของพืช การวิเคราะห์ความสัมพันธ์ระห ว่างกระบวนการทาง
สรีรวิทยากับการเจริญเติบโตและการให้ผลผลิต และการประยุกต์ใช้ความรู้ทางสรีรวิทยาในการผลิตและปรับปรุง
ผลผลิตพืช
