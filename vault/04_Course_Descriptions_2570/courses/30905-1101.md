# 30905*1101 การปรับปรุงพันธุ์พืช

> [!source] แหล่งข้อมูล
> PDF หน้า 83

30905*1101 การปรับปรุงพันธุ์พืช                  2-2-3  
Plant Breeding 
อ้างอิงมาตรฐาน  
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบายหลักการปรับปรุงพันธุ์ การถ่ายทอดลักษณะ และปัจจัยที่เกี่ยวข้องกับการปรับปรุงพันธุ์พืช 
2. วิเคราะห์ลักษณะและธรรมชาติการผสมพันธุ์ของพืชเพื่อกำหนดแนวทางการปรับปรุงพันธุ์ตาม
วัตถุประสงค์ 
3. เลือกวิธีการปรับปรุงพันธุ์พืชให้เหมาะสมกับธรรมชาติของพืชและวัตถุประสงค์ของการปรับปรุงพันธุ์ 
4. คัดเลือกพืชเพื่อการปรับปรุงพันธุ์ตามลักษณะและวัตถุประสงค์ที่กำหนด 
5. ดำเนินงานปรับปรุงพันธุ์พืชตามวิธีการ หลักการ และกระบวนการที่กำหนด 
6. ประยุกต์ใช้เทคโนโลยีที่เกี่ยวข้องในการปรับปรุงพันธุ์พืชอย่างรับผิดชอบและมีจรรยาบรรณ 
จุดประสงค์รายวิชา  เพื่อให้    
1. เข้าใจหลักการ วิธีการ และปัจจัยที่เกี่ยวข้องกับการปรับปรุงพันธุ์พืช 
2. สามารถคัดเลือกพืชและเลือกวิธีการปรับปรุงพันธุ์ให้เหมาะสมกับธรรมชาติของพืชและวัตถุประสงค์ 
3. สามารถประยุกต์ใช้วิธีการและเทคโนโลยีที่เกี่ยวข้องในการปรับปรุงพันธุ์พืช 
4. มีเจตคติและกิจนิสัยที่ดีในการศึกษาและปฏิบัติงานด้วยความรับผิดชอบ มีวินัย ซื่อสัตย์ ขยัน อดทน 
และมีจรรยาบรรณ 
สมรรถนะรายวิชา  
1. วางแผนการปรับปรุงพันธุ์พืชโดยเลือกวิธีการให้เหมาะสมกับธรรมชาติของพืชและวัตถุประสงค์ของการ
ปรับปรุงพันธุ์ 
2. คัดเลือกและดำเนินงานปรับปรุงพันธุ์พืชตามหลักการ กระบวนการ และวัตถุประสงค์ที่กำหนด 
3. ประยุกต์ใช้วิธีการและเทคโนโลยีที่เกี่ยวข้องในการปรับปรุงพันธุ์พืชอย่างรับผิดชอบและมีจรรยาบรรณ 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับ ความหมายและความสำคัญของการปรับปรุงพันธุ์พืช หลักการปรับปรุงพันธุ์พืช
เบื้องต้น ลักษณะและธรรมชาติการผสมพันธุ์ของพืช พืชผสมตัวเองและพืชผสมข้าม การถ่ายทอดลักษณะและอิทธิพล
ของสิ่งแวดล้อมต่อการแสดงออกของลักษณะพืช การคัดเลือกพืช การวางแผนแ ละวิธีการปรับปรุงพันธุ์พืชผสมตัวเอง
และพืชผสมข้าม การสร้างพันธุ์ลูกผสม การปรับปรุงพันธุ์พืชต่างชนิด การปรับปรุงพันธุ์พืชให้ต้านทานต่อโรคและ
แมลง การใช้เซลล์พันธุศาสตร์และเทคโนโลยีชีวภาพในการปรับปรุงพันธุ์พืช และการประยุกต์ใช้ในการปรับปรุงพันธุ์
พืชอย่างรับผิดชอบและมีจรรยาบรรณ
