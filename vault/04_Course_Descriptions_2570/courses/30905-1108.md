# 30905*1108 เท โนโลยีการผลิตพืชไร่เศรษฐกิจ

30905*1108 เทคโนโลยีการผลิตพืชไร่เศรษฐกิจ                2-3-3 
Economic Field Crops Technology  
อ้างอิงมาตรฐาน 
- 
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. ประยุกต์ใช้ความรู้ในการวางแผนและจัดการการผลิตพืช ให้เหมาะสมกับชนิดพืช สภาพพื้นที่ และปัจจัย
การผลิตได้ 
2. วิเคราะห์ปัจจัยที่มีผลต่อการเจริญเติบโต ผลผลิต และคุณภาพของพืช เพื่อกำหนดแนวทางการจัดการ
ผลิตที่เหมาะสมได้ 
3. เลือกใช้เทคโนโลยีและวิธีการผลิตที่เหมาะสม เพื่อเพิ่มประสิทธิภาพการผลิตและลดต้นทุนการผลิตได้ 
4. จัดการทรัพยากรในการผลิตพืชอย่างมีประสิทธิภาพและยั่งยืน โดยคำนึงถึงความคุ้มค่าและผลกระทบต่อ
สิ่งแวดล้อมได้ 
จุดประสงค์รายวิชา  เพื่อให้ 
1. มีความรู้และความเข้าใจเกี่ยวกับความสำคัญ ลักษณะ และระบบการผลิตของพืชไร่เศรษฐกิจที่สำคัญ 
2. เข้าใจความสัมพันธ์ระหว่างพันธุ์ สภาพแวดล้อม และการจัดการที่มีผลต่อการเจริญเติบโต ผลผลิต และ
คุณภาพของพืชไร่เศรษฐกิจ 
3. มีทักษะในการเลือกใช้และประยุกต์ใช้เทคโนโลยีการผลิตที่เหมาะสมกับชนิดพืชและสภาพพื้นที่ 
4. สามารถวิเคราะห์ปัญหาและประเมินประสิทธิภาพการผลิต เพื่อปรับปรุงผลผลิต คุณภาพ ต้นทุน และ
ความยั่งยืนของระบบการผลิต 
สมรรถนะรายวิชา 
1. จำแนกและอธิบายลักษณะ ความสำคัญ และความต้องการพื้นฐานของพืชไร่เศรษฐกิจแต่ละชนิด 
2. วางแผนการผลิตพืชไร่เศรษฐกิจโดยพิจารณาพันธุ์ สภาพดิน น้ำ ภูมิอากาศ และปัจจัยการผลิต 
3. ปฏิบัติและจัดการการผลิตพืชไร่เศรษฐกิจ ตั้งแต่การเตรียมพื้นที่ การปลูก การจัดการน้ำและปุ๋ย จนถึง
การเก็บเกี่ยว 
4. วิเคราะห์และแก้ไขปัญหาด้านโรค แมลง วัชพืช และปัจจัยจำกัดผลผลิตโดยเลือกใช้วิธีการจัดการที่
เหมาะสม 
5. ประเมินผลผลิต คุณภาพ และประสิทธิภาพการผลิต และเลือกใช้เทคโนโลยีเพื่อปรับปรุงระบบการผลิต
พืชไร่เศรษฐกิจ 
คำอธิบายรายวิชา  
 ศึกษาและปฏิบัติเกี่ยวกับความสำคัญและระบบการผลิตพืชไร่เศรษฐกิจ (ไม่น้อยกว่า 3 ชนิด) ปัจจัยที่มีผลต่อ
การเจริญเติบโตและผลผลิต การเลือกใช้พันธุ์ การเตรียมพื้นที่และการปลูก การจัดการดินและปุ๋ย การจัดการน้ำ การ
จัดการวัชพืช โรค และแมลงศัตรูพืช การใช้เครื่องจักรกลและเทคโนโลยีในการผลิต การประเมินการเจริญเติบโต 
ผลผลิต และคุณภาพ การเก็บเกี่ยวและกา รจัดการหลังการเก็บเกี่ยว ตลอดจนการประยุกต์ใช้เทคโนโลยีเพื่อเพิ่ม
ประสิทธิภาพ ลดต้นทุน และเพิ่มความยั่งยืนของการผลิตพืชไร่เศรษฐกิจ
