# 30905*1109 หลักการส่งเสริมการเกษตร

> [!source] แหล่งข้อมูล
> PDF หน้า 91

30905*1109 หลักการส่งเสริมการเกษตร               2-3-3 
Principles of Agricultural Extension  
อ้างอิงมาตรฐาน 
- 
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบายหลักการ แนวคิด บทบาท และกระบวนการส่งเสริมการเกษตร รวมถึงบทบาทของนักส่งเสริม
การเกษตรและผู้มีส่วนเกี่ยวข้องได้ 
2. ประยุกต์ใช้ความรู้และกระบวนการส่งเสริมการเกษตร ในการทำงานร่วมกับเกษตรกร กลุ่มเกษตรกร 
และหน่วยงานที่เกี่ยวข้องได้ 
3. วิเคราะห์ปัญหาและความต้องการของเกษตรกรและชุมชน เพื่อวางแผนและดำเนินกิจกรรมส่งเสริม
การเกษตรให้สอดคล้องกับบริบทของพื้นที่ได้ 
4. ถ่ายทอดความรู้และเทคโนโลยีทางการเกษตร รวมทั้งติดตามและประเมินผลกิจกรรมส่งเสริมการเกษตร 
เพื่อปรับปรุงการดำเนินงานให้มีประสิทธิภาพได้ 
จุดประสงค์รายวิชา  เพื่อให้ 
1. มีความรู้และความเข้าใจเกี่ยวกับหลักการ แนวคิด บทบาท และระบบงานส่งเสริมการเกษตร 
2. เข้าใจเกษตรกร กลุ่มเกษตรกร ชุมชน และปัจจัยที่เกี่ยวข้องกับการยอมรับและการนำความรู้หรือ
เทคโนโลยีไปใช้ในพื้นที่ 
3. มีทักษะในการสื่อสาร การถ่ายทอดความรู้ การทำงานร่วมกับเกษตรกร และการจัดกระบวนการเรียนรู้ 
4. สามารถประยุกต์ใช้กระบวนการส่งเสริมการเกษตรในการวางแผน ดำเนินงาน และประเมินผลการ
พัฒนาการเกษตร 
สมรรถนะรายวิชา 
1. อธิบายหลักการ แนวคิด บทบาท รูปแบบ และวิธีการส่งเสริมการเกษตรได้ 
2. สำรวจและวิเคราะห์ปัญหา ความต้องการ และข้อมูลพื้นฐานของเกษตรกรและพื้นที่เพื่อใช้ในการ
วางแผนงานส่งเสริม 
3. สื่อสาร ถ่ายทอดความรู้ และจัดกิจกรรมการเรียนรู้ทางการเกษตรให้เหมาะสมกับกลุ่มเป้าหมาย 
4. วางแผนและดำเนินโครงการหรือกิจกรรมส่งเสริมการเกษตรโดยประยุกต์ใช้กระบวนการมีส่วนร่วม 
5. ติดตามและประเมินผลการดำเนินงานส่งเสริมการเกษตร และนำผลการประเมินไปปรับปรุงการ
ดำเนินงาน 
คำอธิบายรายวิชา  
 ศึกษาและปฏิบัติเกี่ยวกับหลักการ แนวคิด ความสำคัญ บทบาท และพัฒนาการของการส่งเสริมการเกษตร 
ระบบและรูปแบบการส่งเสริมการเกษตร นักส่งเสริมและกลุ่มเป้าหมาย การเรียนรู้และการยอมรับของเกษตรกร การ
สื่อสารและการถ่ายทอดความรู้และเทคโนโลยีทางการเกษตร วิธีการและสื่อในกา รส่งเสริมการเกษตร การวิเคราะห์
ปัญหาและความต้องการของเกษตรกร การวางแผนและจัดทำโครงการส่งเสริมการเกษตร การทำงานร่วมกับเกษตรกร
และหน่วยงานที่เกี่ยวข้อง การติดตามและประเมินผล ตลอดจนการประยุกต์ใช้กระบวนการส่งเสริมการเกษตรในการ
พัฒนาการผลิตและคุณภาพชีวิตของเกษตรกร
