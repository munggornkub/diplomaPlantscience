# 30905*1110 เท โนโลยีการผลิตข้าว

30905*1110 เทคโนโลยีการผลิตข้าว                    2-3-3  
Rice Cultivation Production Technology  
อ้างอิงมาตรฐาน    
- 
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. อธิบายหลักการ กระบวนการ และปัจจัยที่มีผลต่อการเจริญเติบโตและผลผลิตข้าว 
2. วิเคราะห์ข้อมูลพื้นที่และทรัพยากรเพื่อวางแผนการผลิตข้าวให้เหมาะสมกับสภาพการผลิต 
3. ปฏิบัติการเพาะปลูกและดูแลรักษาข้าวตามแผนการผลิตและหลักการปฏิบัติทางการเกษตรที่ดี 
4. เลือกใช้วิธีการและเทคโนโลยีในการจัดการปัจจัยการผลิตเพื่อเพิ่มประสิทธิภาพและผลผลิตข้าวต่อพื้นที่
อย่างเหมาะสม 
5. เก็บเกี่ยวและจัดการผลผลิตข้าวหลังการเก็บเกี่ยวเบื้องต้นให้เหมาะสมกับคุณภาพของผลผลิต 
6. เลือกแนวทางจัดการและใช้ประโยชน์จากวัสดุเหลือทิ้งหลังการเก็บเกี่ยวอย่างเหมาะสม โดยคำนึงถึงการ
ใช้ทรัพยากรและสิ่งแวดล้อม 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจหลักการ กระบวนการ และปัจจัยที่เกี่ยวข้องกับการผลิตข้าว 
2. สามารถวิเคราะห์และวางแผนการผลิตข้าวให้เหมาะสมกับสภาพพื้นที่และทรัพยากร 
3. สามารถปฏิบัติและจัดการการผลิตข้าวโดยเลือกใช้วิธีการและเทคโนโลยีเพื่อเพิ่มประสิทธิภาพและ
ผลผลิตต่อพื้นที่ 
4. สามารถวิเคราะห์ปัญหาและปรับปรุงการจัดการการผลิตข้าวตามข้อมูลและสถานการณ์ 
5. มีเจตคติและกิจนิสัยที่ดีในการผลิตข้าวอย่างรับผิดชอบ ปลอดภัย และคำนึงถึงการอนุรักษ์
ทรัพยากรธรรมชาติ 
สมรรถนะรายวิชา  
1. วางแผนการผลิตข้าวให้เหมาะสมกับสภาพพื้นที่ ทรัพยากร และเป้าหมายการผลิต 
2. จัดการกระบวนการผลิต ผลผลิต และวัสดุเหลือจากการผลิตข้าว โดยเลือกใช้วิธีการและเทคโนโลยีที่
เหมาะสมตามหลักการปฏิบัติทางการเกษตรที่ดี 
3. ใช้ข้อมูลการผลิตในการประเมิน แก้ไขปัญหา และปรับปรุงการจัดการเพื่อเพิ่มประสิทธิภาพและผลผลิต
ข้าวต่อพื้นที่อย่างเหมาะสม 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับ หลักการและกระบวนการผลิตข้าว ปัจจัยที่มีผลต่อการเจริญเติบโตและผลผลิต 
การสำรวจและวิเคราะห์สภาพพื้นที่และทรัพยากรในท้องถิ่น การวางแผนการผลิต การเพาะปลูกและดูแลรักษาข้าว 
การจัดการปัจจัยการผลิตและการประยุกต์ใช้เทคโนโลยีเพื่อเพิ่มประสิทธิ ภาพและผลผลิตต่อพื้นที่ การผลิตข้าวตาม
หลักการปฏิบัติทางการเกษตรที่ดี การเก็บเกี่ยวและการจัดการผลผลิตหลังการเก็บเกี่ยวเบื้องต้น การวิเคราะห์และ
แก้ไขปัญหาที่เกิดขึ้นในกระบวนการผลิต การบันทึกและใช้ข้อมูลเพื่อประเมินและปรับปรุง การผลิตข้าว การจัดการ
และใช้ประโยชน์จากวัสดุเหลือ ทิ้งหลังการเก็บเกี่ยว โดยคำนึงถึงความปลอดภัย การใช้ทรัพยากรอย่างเหมาะสม และ
สิ่งแวดล้อม
