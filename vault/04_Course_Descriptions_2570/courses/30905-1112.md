# 30905*1112 การผลิตเมล็ดพันธุ์เพื่อการ ้า

> [!source] แหล่งข้อมูล
> PDF หน้า 94

30905*1112 การผลิตเมล็ดพันธุ์เพื่อการค้า                2-3-3   
Commercial Seed Production 
อ้างอิงมาตรฐาน   
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs) 
1. วางแผนการผลิตเมล็ดพันธุ์เพื่อการค้าให้เหมาะสมกับชนิดพืช พื้นที่ และมาตรฐานการผลิต 
2. ปฏิบัติการผลิตและจัดการแปลงเมล็ดพันธุ์เพื่อให้ได้เมล็ดพันธุ์ที่มีคุณภาพ 
3. ปฏิบัติการเก็บเกี่ยว ปรับปรุงสภาพ ตรวจสอบคุณภาพ บรรจุ และเก็บรักษาเมล็ดพันธุ์ตามมาตรฐาน 
4. เตรียมเมล็ดพันธุ์และข้อมูลหรือเอกสารที่เกี่ยวข้องสำหรับการจำหน่ายและส่งออกตามข้อกำหนด 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจหลักการและกระบวนการผลิตเมล็ดพันธุ์เพื่อการค้า 
2. สามารถวางแผนและปฏิบัติการผลิตเมล็ดพันธุ์ในแปลง การเก็บเกี่ยว และการจัดการหลังการเก็บเกี่ยว
ได้อย่างเหมาะสม 
3. สามารถปรับปรุงสภาพ ตรวจสอบคุณภาพ บรรจุ และเก็บรักษาเมล็ดพันธุ์ตามมาตรฐาน 
4. สามารถเตรียมเมล็ดพันธุ์และเอกสารที่เกี่ยวข้องสำหรับการจำหน่ายและส่งออก โดยคำนึงถึงคุณภาพ 
ความปลอดภัย และข้อกำหนดทางกฎหมาย 
5. มีความรับผิดชอบ รอบคอบ และตระหนักถึงความสำคัญของคุณภาพเมล็ดพันธุ์ในการประกอบอาชีพ 
สมรรถนะรายวิชา  
1. วางแผนการผลิตเมล็ดพันธุ์เพื่อการค้าตามชนิดพืชและมาตรฐานการผลิต 
2. ปฏิบัติการผลิตและจัดการแปลงเมล็ดพันธุ์ตั้งแต่การปลูกจนถึงการเก็บเกี่ยว 
3. ปรับปรุงสภาพ ตรวจสอบคุณภาพ บรรจุ และเก็บรักษาเมล็ดพันธุ์ตามหลักการและมาตรฐาน 
4. จัดการเมล็ดพันธุ์เพื่อการจำหน่ายและส่งออกตามมาตรฐานและข้อกำหนดที่เกี่ยวข้อง 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับหลักการผลิตเมล็ดพันธุ์เพื่อการค้า การวางแผนและการจัดการแปลงผลิตเมล็ดพันธุ์ 
การเลือกพื้นที่และพันธุ์ การปลูกและดูแลรักษา การรักษาความบริสุทธิ์ของพันธุ์ การตรวจแปลง การเก็บเกี่ยวและการ
จัดการหลังการเก็บเกี่ยว การปรับปรุงสภาพเมล็ดพันธุ์  การตรวจสอบคุณภาพ การบรรจุ การเก็บรักษา การรับรอง
และมาตรฐานเมล็ดพันธุ์ กฎหมายที่เกี่ยวข้อง และการเตรียมเมล็ดพันธุ์เพื่อการจำหน่ายและส่งออก
