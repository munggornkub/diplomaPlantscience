# 30905*1113 ระบบการปลูกพืชอัจฉริยะ

30905*1113  ระบบการปลูกพืชอัจฉริยะ                2-3-3  
Smart Farm  
อ้างอิงมาตรฐาน 
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา  
1. อธิบายปัจจัยที่มีผลต่อการเจริญเติบโตของพืชและหลักการทำงานของระบบฟาร์มอัจฉริยะ 
2. เลือกใช้วัสดุ อุปกรณ์ และระบบควบคุมให้เหมาะสมกับปัจจัยการผลิตพืช 
3. ใช้ระบบอัตโนมัติและแอปพลิเคชันในการติดตามและควบคุมปัจจัยการผลิตพืช 
4. วางแผนการใช้เทคโนโลยีฟาร์มอัจฉริยะให้เหมาะสมกับการผลิตพืชและสภาพการผลิต 
5. เลือกใช้เทคโนโลยีและพลังงานทดแทนในโรงเรือนอัจฉริยะให้เหมาะสมกับการใช้งานและการผลิตพืช 
จุดประสงค์รายวิชา   
1. เข้าใจปัจจัยที่มีผลต่อการเจริญเติบโตของพืชและหลักการทำงานของระบบฟาร์มอัจฉริยะ 
2. สามารถเลือกใช้วัสดุ อุปกรณ์ ระบบอัตโนมัติ และแอปพลิเคชันให้เหมาะสมกับการควบคุมปัจจัยการ
ผลิตพืช 
3. สามารถใช้งานและติดตามระบบฟาร์มอัจฉริยะเพื่อสนับสนุนการจัดการการผลิตพืช 
4. สามารถเลือกใช้ระบบพลังงานทดแทนในโรงเรือนอัจฉริยะให้เหมาะสมกับการใช้งาน 
5. มีเจตคติและกิจนิสัยที่ดีในการใช้เทคโนโลยีอย่างรับผิดชอบ รอบคอบ และคำนึงถึงการใช้ทรัพยากรอย่าง
เหมาะสม 
สมรรถนะรายวิชา   
1. วางแผนและเลือกใช้วัสดุ อุปกรณ์ และเทคโนโลยีฟาร์มอัจฉริยะให้เหมาะสมกับปัจจัยการผลิตพืช 
2. ใช้ระบบอัตโนมัติและแอปพลิเคชันในการติดตามและควบคุมปัจจัยการผลิตพืช 
3. ประยุกต์ใช้เทคโนโลยีฟาร์มอัจฉริยะและพลังงานทดแทนเพื่อสนับสนุนการจัดการการผลิตพืชอย่าง
เหมาะสม 
คำอธิบายรายวิชา   
ศึกษาและปฏิบัติเกี่ยวกับ ปัจจัยที่มีผลต่อการเจริญเติบโตของพืช หลักการของฟาร์มอัจฉริยะ วัสดุและ
อุปกรณ์สำหรับติดตามและควบคุมปัจจัยการผลิต ระบบการจัดการการผลิตอัตโนมัติ การเลือกใช้และใช้งานแอปพลิเค
ชันในการติดตามและควบคุมการผลิต การวางแผนและประยุกต์ใช้เทคโนโลยี ฟาร์มอัจฉริยะในการผลิตพืช ระบบ
พลังงานทดแทนในโรงเรือนอัจฉริยะ และการเลือกใช้เทคโนโลยีให้เหมาะสมกับการผลิตพืชและการใช้ทรัพยากร
