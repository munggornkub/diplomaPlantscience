# 30905*1115 การขยายพันธุ์พืชเพื่อการ ้า

> [!source] แหล่งข้อมูล
> PDF หน้า 97

30905*1115 การขยายพันธุ์พืชเพื่อการค้า                2-3-3  
Commercial Plant Propagation 
อ้างอิงมาตรฐาน  
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา  
1. อธิบายหลักการ ปัจจัย และวิธีการขยายพันธุ์พืชที่เหมาะสมกับพืชแต่ละประเภท 
2. วางแผนการขยายพันธุ์พืชโดยพิจารณาชนิดพืช สภาพการผลิต และความต้องการของตลาด 
3. เตรียมพันธุ์พืช สถานที่ วัสดุ และอุปกรณ์สำหรับการขยายพันธุ์พืชได้เหมาะสมกับวิธีการที่เลือกใช้ 
4. ปฏิบัติการขยายพันธุ์พืชด้วยวิธีที่เหมาะสมกับชนิดพืชตามหลักและขั้นตอนการปฏิบัติ 
5. ดูแลรักษาพันธุ์พืชหลังการขยายพันธุ์ให้มีคุณภาพและพร้อมสำหรับการนำไปใช้หรือจำหน่าย 
6. เตรียมและบรรจุพันธุ์พืชสำหรับการจำหน่ายให้เหมาะสมกับชนิดและคุณภาพของพันธุ์พืช 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจหลักการ ปัจจัย เทคนิค และวิธีการขยายพันธุ์พืช 
2. สามารถวางแผนการขยายพันธุ์พืชให้เหมาะสมกับชนิดพืชและความต้องการของตลาด 
3. สามารถเตรียมวัสดุ อุปกรณ์ พันธุ์พืช และปฏิบัติการขยายพันธุ์พืชด้วยวิธีที่เหมาะสม 
4. สามารถดูแลและจัดการพันธุ์พืชหลังการขยายพันธุ์เพื่อเตรียมสำหรับการจำหน่าย 
5. มีเจตคติและกิจนิสัยที่ดีในการปฏิบัติงานอย่างรับผิดชอบ รอบคอบ และคำนึงถึงการใช้ทรัพยากรอย่าง
เหมาะสม 
สมรรถนะรายวิชา  
1. วางแผนการขยายพันธุ์พืชเพื่อการค้าให้เหมาะสมกับชนิดพืชและความต้องการของตลาด 
2. ปฏิบัติการขยายพันธุ์พืชโดยเลือกใช้วิธีการ วัสดุ อุปกรณ์ และสภาพแวดล้อมให้เหมาะสมกับชนิดพืช 
3. ดูแลและจัดการพันธุ์พืชหลังการขยายพันธุ์ให้มีคุณภาพเหมาะสมสำหรับการจำหน่าย โดยใช้ทรัพยากร
อย่างเหมาะสม 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับ ความสำคัญและหลักการขยายพันธุ์พืช ปัจจัยที่เกี่ยวข้องกับการขยายพันธุ์พืช 
ความต้องการของตลาดพันธุ์พืช โรงเรือน สถานที่ วัสดุและอุปกรณ์ในการขยายพันธุ์พืช การวางแผนการขยายพันธุ์พืช
เพื่อการค้า การเตรียมพันธุ์พืช การเลือกและปฏิบัติการขยายพันธุ์พืชด้วยวิธีและเทคนิคที่เหมาะสม การดูแลรักษาและ
ประเมินคุณภาพพันธุ์พืชหลังการขยายพันธุ์ และการเตรียมและบรรจุพันธุ์พืชเพื่อการจำหน่าย โดยคำนึงถึงการใช้
ทรัพยากรอย่างเหมาะสม
