# 30905*1119 เกษตรแม่นยำ

> [!source] แหล่งข้อมูล
> PDF หน้า 101

30905*1119  เกษตรแม่นยำ                 2-3-3 
  Precision Agriculture 
อ้างอิงมาตรฐาน 
- 
ผลลัพธ์การเรียนรู้ระดับรายวิชา 
 1. สำรวจและเก็บรวบรวมข้อมูลแปลงเกษตร โดยประยุกต์ใช้เทคโนโลยีเกษตรแม่นยำ เช่น ระบบนำทางด้วย
ดาวเทียม เซนเซอร์ และอากาศยานไร้คนขับได้ 
2. จัดการและวิเคราะห์ข้อมูลทางการเกษตร โดยประยุกต์ใช้ระบบสารสนเทศทางภูมิศาสตร์ และเทคโนโลยี
อินเทอร์เน็ตในทุกสรรพสิ่งได้ 
3. บูรณาการข้อมูลและเทคโนโลยีเกษตรแม่นยำ เพื่อสนับสนุนการตัดสินใจ วางแผน และจัดการฟาร์มได้
อย่างมีประสิทธิภาพและเหมาะสมกับสภาพพื้นที่ 
จุดประสงค์รายวิชา  เพื่อให้ 
 1. มีความรู้และความเข้าใจเกี่ยวกับหลักการ แนวคิด และกระบวนการของเกษตรแม่นยำ 
2. เข้าใจบทบาทของข้อมูล เทคโนโลยีดิจิทัล และเครื่องมือสมัยใหม่ในการจัดการฟาร์ม 
3. มีทักษะในการสำรวจ เก็บรวบรวม จัดการ และวิเคราะห์ข้อมูลทางการเกษตรเพื่อสนับสนุนการตัดสินใจ 
4. ตระหนักถึงความสำคัญของการใช้เทคโนโลยีเพื่อเพิ่มประสิทธิภาพการผลิต ลดต้นทุน และใช้ทรัพยากร
ทางการเกษตรอย่างเหมาะสมและยั่งยืน 
สมรรถนะรายวิชา 
 1. สำรวจและจัดเก็บข้อมูลตำแหน่งและข้อมูลเชิงพื้นที่ของแปลงเกษตรด้วยระบบนำทางด้วยดาวเทียม และ
จัดทำข้อมูลด้วยระบบสารสนเทศทางภูมิศาสตร์ 
2. ใช้เซนเซอร์และอุปกรณ์อินเทอร์เน็ตในทุกสรรพสิ่งในการตรวจวัดและติดตามสภาพดิน น้ำ อากาศ และ
พืช 
3. ใช้อากาศยานไร้คนขับ และการรับรู้ระยะไกลในการสำรวจและประเมินสภาพแปลงเกษตร 
4. จัดการ วิเคราะห์ และแปลผลข้อมูลทางการเกษตรด้วยซอฟต์แวร์และเครื่องมือดิจิทัลเพื่อสนับสนุนการ
ตัดสินใจ 
5. ประยุกต์ใช้ข้อมูลในการวางแผนการให้น้ำ ปุ๋ย และสารป้องกันกำจัดศัตรูพืชแบบแปรผันตามพื้นที่  
คำอธิบายรายวิชา  
 ศึกษาและปฏิบัติเกี่ยวกับหลักการ แนวคิด และกระบวนการของเกษตรแม่นยำ การใช้ข้อมูลและเทคโนโลยี
ดิจิทัลเพื่อการจัดการฟาร์ม ระบบนำทางด้วยดาวเทียม และระบบสารสนเทศภูมิศาสตร์ การสำรวจและจัดเก็บข้อมูล
แปลงเกษตรด้วยอากาศยานไร้คนขับ และการรับรู้ระยะไกล การใช้เซนเซอร์ตรวจวัดสภาพดิน น้ำ อากาศ และพืช การ
ประยุกต์ใช้อินเทอร์เน็ตของสรรพสิ่ง และระบบอัตโนมัติในฟาร์ม การจัดการและวิเคราะห์ข้อมูลทางการเกษตรด้วย
ซอฟต์แวร์ การจัดทำข้อมูลและแผนที่เพื่อการจัดการแปลง และการประยุกต์ใช้ข้อมูลในการให้น้ำ ปุ๋ย และสารป้องกัน
กำจัดศัตรูพืชแบบแปรผันตามพื้นที่
