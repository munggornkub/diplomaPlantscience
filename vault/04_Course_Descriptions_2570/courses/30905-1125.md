# 30905*1125 ผลิตภัณฑ์เ มีเกษตรและการประยุกต์ใช้

30905*1125  ผลิตภัณฑ์เคมีเกษตรและการประยุกต์ใช้               2-3-3  
Agrochemical Products and Applications  
อ้างอิงมาตรฐาน   
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา  
1. จำแนกและอธิบายคุณสมบัติและการใช้ผลิตภัณฑ์เคมีเกษตรประเภทต่าง ๆ ได้ 
2. อ่านและแปลข้อมูลจากฉลากผลิตภัณฑ์ พร้อมคำนวณอัตราและเตรียมผลิตภัณฑ์เพื่อใช้งานได้อย่าง
ถูกต้อง 
3. เลือกใช้ผลิตภัณฑ์เคมีเกษตรให้เหมาะสมกับพืช ปัญหา และสภาพการผลิต โดยคำนึงถึงประสิทธิภาพ 
ความปลอดภัย และผลกระทบต่อสิ่งแวดล้อม 
4. สื่อสาร สาธิต และให้คำแนะนำการใช้ผลิตภัณฑ์เคมีเกษตรแก่เกษตรกรได้อย่างถูกต้องตามฉลากและ
ข้อกำหนดที่เกี่ยวข้อง 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจประเภท คุณสมบัติ และหลักการใช้ผลิตภัณฑ์เคมีเกษตรในการผลิตพืช 
2. สามารถอ่านฉลาก คำนวณอัตรา เตรียม ผสม และใช้ผลิตภัณฑ์เคมีเกษตรได้อย่างถูกต้องและปลอดภัย 
3. สามารถวิเคราะห์ข้อมูลและเลือกผลิตภัณฑ์ให้เหมาะสมกับพืช ปัญหา และสภาพการผลิต 
4. สามารถสื่อสาร สาธิต และให้คำแนะนำเกี่ยวกับผลิตภัณฑ์และการใช้งานแก่เกษตรกรหรือผู้ใช้ 
5. มีความรับผิดชอบและจริยธรรมในการแนะนำและใช้ผลิตภัณฑ์ โดยคำนึงถึงความปลอดภัย ผลผลิต 
ผู้บริโภค และสิ่งแวดล้อม 
สมรรถนะรายวิชา  
1. จำแนกผลิตภัณฑ์เคมีเกษตรและเลือกใช้ตามลักษณะงานด้านการผลิตพืช 
2. อ่านฉลาก คำนวณอัตรา เตรียมและผสมผลิตภัณฑ์ตามคำแนะนำและหลักความปลอดภัย 
3. วิเคราะห์ปัญหาและเลือกผลิตภัณฑ์ที่เหมาะสมกับพืชและสถานการณ์การผลิต 
4. สาธิตและให้คำแนะนำการใช้ผลิตภัณฑ์แก่เกษตรกรหรือผู้ใช้ตามหลักวิชาการ ฉลาก และข้อกำหนดที่
เกี่ยวข้อง 
5. ปฏิบัติงานเกี่ยวกับผลิตภัณฑ์เคมีเกษตรโดยคำนึงถึงความปลอดภัย ความรับผิดชอบ และผลกระทบต่อ
สิ่งแวดล้อม 
คำอธิบายรายวิชา  
ศึกษาและปฏิบัติเกี่ยวกับผลิตภัณฑ์เคมีเกษตรและการใช้ในการผลิตพืช ประเภท สมบัติ และการเลือกใช้ปุ๋ย 
สารปรับปรุงดิน สารป้องกันกำจัดศัตรูพืช สารชีวภาพและชีวภัณฑ์ สารควบคุมการเจริญเติบโตของพืช และสารเสริม
ประสิทธิภาพ การอ่านฉลากและข้อมูลผลิตภัณฑ์ การคำนวณอัตรา การเตรียมและผสมสาร การใช้และเก็บรักษาอย่าง
ถูกต้องและปลอดภัย การวิเคราะห์ปัญหาและเลือกผลิตภัณฑ์ให้เหมาะสมกับพืชและสถานการณ์ การสาธิตและให้
คำแนะนำแก่เกษตรกร ตลอดจนมาตรฐาน กฎหมาย และจริยธรรมที่เกี่ยวข้อง
