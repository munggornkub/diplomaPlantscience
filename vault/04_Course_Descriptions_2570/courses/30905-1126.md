# 30905*1126 การท่องเที่ยวเชิงเกษตร

> [!source] แหล่งข้อมูล
> PDF หน้า 108

30905*1126 การท่องเที่ยวเชิงเกษตร                  2-3-3 
Agritourism 
อ้างอิงมาตรฐาน  
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา  
1. อธิบายหลักการ รูปแบบ และองค์ประกอบของการท่องเที่ยวเชิงเกษตร 
2. สำรวจและวิเคราะห์ศักยภาพของพื้นที่ ทรัพยากรเกษตร วิถีชีวิต และภูมิปัญญาท้องถิ่นเพื่อใช้ในการ
พัฒนาการท่องเที่ยวเชิงเกษตร 
3. ออกแบบเส้นทางและกิจกรรมการท่องเที่ยวเชิงเกษตรให้เหมาะสมกับทรัพยากร พื้นที่ และ
กลุ่มเป้าหมาย 
4. วางแผนการบริการ คำนวณต้นทุน และกำหนดราคากิจกรรมการท่องเที่ยวเชิงเกษตร 
5. จัดทำสื่อประชาสัมพันธ์และเลือกใช้ช่องทางการตลาดดิจิทัลให้เหมาะสมกับกิจกรรมและกลุ่มเป้าหมาย 
6. จัดกิจกรรมการท่องเที่ยวเชิงเกษตรโดยคำนึงถึงความปลอดภัย การมีส่วนร่วมของชุมชน สิ่งแวดล้อม 
และการใช้ทรัพยากรอย่างเหมาะสม 
จุดประสงค์รายวิชา เพื่อให้   
1. เข้าใจหลักการ รูปแบบ และองค์ประกอบของการท่องเที่ยวเชิงเกษตร 
2. สามารถสำรวจและวิเคราะห์ศักยภาพของพื้นที่ ทรัพยากรเกษตร วิถีชีวิต และภูมิปัญญาท้องถิ่น 
3. สามารถวางแผนการใช้พื้นที่ เส้นทาง กิจกรรม และการบริการให้เหมาะสมกับกลุ่มเป้าหมาย 
4. สามารถวางแผนต้นทุน ราคา การประชาสัมพันธ์ และการตลาดสำหรับกิจกรรมการท่องเที่ยวเชิงเกษตร 
5. สามารถจัดกิจกรรมการท่องเที่ยวเชิงเกษตรอย่างรับผิดชอบ โดยคำนึงถึงความปลอดภัย ชุมชน 
ทรัพยากร และสิ่งแวดล้อม 
สมรรถนะรายวิชา   
1. ประเมินศักยภาพของพื้นที่และทรัพยากรเพื่อพัฒนากิจกรรมการท่องเที่ยวเชิงเกษตรให้เหมาะสมกับ
บริบทและกลุ่มเป้าหมาย 
2. วางแผนและพัฒนากิจกรรมการท่องเที่ยวเชิงเกษตรจากทรัพยากรเกษตร วิถีชีวิต และภูมิปัญญาท้องถิ่น 
3. วางแผนการบริการ ต้นทุน ราคา การประชาสัมพันธ์ และการตลาดสำหรับการท่องเที่ยวเชิงเกษตร 
4. จัดกิจกรรมการท่องเที่ยวเชิงเกษตรโดยคำนึงถึงความปลอดภัย การมีส่วนร่วมของชุมชน สิ่งแวดล้อม 
และการใช้ทรัพยากรอย่างยั่งยืน 
คำอธิบายรายวิชา   
ศึกษาและปฏิบัติเกี่ยวกับแนวคิดและรูปแบบการท่องเที่ยวเชิงเกษตร การสำรวจและวิเคราะห์ศักยภาพของ
พื้นที่ ทรัพยากรเกษตร วิถีชีวิตและภูมิปัญญาท้องถิ่น การออกแบบพื้นที่ เส้นทางและกิจกรรมการท่องเที่ยวเชิงเกษตร 
การสร้างประสบการณ์และการบริการนักท่องเที่ยว การพัฒนาผลิตภัณฑ์และสร้างมูลค่าเพิ่มจากทรัพยากรเกษตร การ
คำนวณต้นทุนและกำหนดราคา การประชาสัมพันธ์และการตลาดดิจิทัล ความปลอดภัยและมาตรฐานที่เกี่ยวข้อง การ
มีส่วนร่วมของชุมชน การอนุรักษ์ทรัพยากรและสิ่งแวดล้อม และการประยุกต์แนวคิด BCG เพื่อพัฒนาการท่องเที่ยว
เชิงเกษตรอย่างยั่งยืน
