# 30905*1127 โ รงงานพิเศษพืชศาสตร์

> [!source] แหล่งข้อมูล
> PDF หน้า 109

30905*1127 โครงงานพิเศษพืชศาสตร์                 1-9-4   
Special Project in Plant Science 
อ้างอิงมาตรฐาน  
-  
ผลลัพธ์การเรียนรู้ระดับรายวิชา   
1. อธิบายหลักการ กระบวนการ และรูปแบบการจัดทำโครงงานในสาขาวิชาชีพพืชศาสตร์ 
2. เลือกประเด็นและจัดทำข้อเสนอโครงงานโดยใช้ข้อมูลและเอกสารที่เกี่ยวข้อง 
3. วางแผนและดำเนินโครงงานโดยบูรณาการความรู้และทักษะในสาขาวิชาชีพ พืชศาสตร์ตามแผนงานที่
กำหนด 
4. เก็บรวบรวม วิเคราะห์ และแปลผลข้อมูลด้วยวิธีการที่เหมาะสมกับลักษณะของโครงงาน 
5. ประเมินผลการดำเนินโครงงานและเสนอแนวทางแก้ไขหรือปรับปรุงงานจากผลที่ได้ 
6. จัดทำรายงานและนำเสนอผลงานโครงงานตามรูปแบบที่กำหนด 
จุดประสงค์รายวิชา  เพื่อให้   
1. เข้าใจหลักการและกระบวนการจัดทำโครงงานในสาขาวิชาชีพพืชศาสตร์ 
2. สามารถเลือกประเด็น ศึกษาข้อมูล วางแผน และจัดทำข้อเสนอโครงงานที่สอดคล้องกับสาขาวิชาชีพ 
3. สามารถบูรณาการความรู้และทักษะเพื่อดำเนินโครงงาน แก้ปัญหา และปรับปรุงการดำเนินงาน 
4. สามารถรวบรวม วิเคราะห์ แปลผล และประเมินผลการดำเนินโครงงาน 
5. สามารถจัดทำรายงานและนำเสนอผลงานโครงงาน 
6. มีความรับผิดชอบ มีวินัย ซื่อสัตย์ และสามารถทำงานร่วมกับผู้อื่นในการดำเนินโครงงาน 
สมรรถนะรายวิชา   
1. วางแผนและจัดทำโครงงานโดยบูรณาการความรู้และทักษะในสาขาวิชาชีพ พืชศาสตร์ เพื่อสร้างหรือ
พัฒนางาน 
2. ดำเนินโครงงานตามแผน เก็บรวบรวมและวิเคราะห์ข้อมูล แก้ไขปัญหา และประเมินผลการดำเนินงาน
อย่างเป็นระบบ 
3. จัดทำรายงานและนำเสนอผลงานโครงงานตามรูปแบบที่กำหนด โดยรับผิดชอบต่อการดำเนินงานของ
ตนเองและการทำงานร่วมกับผู้อื่น 
คำอธิบายรายวิชา   
ศึกษาและปฏิบัติเกี่ยวกับ การบูรณาการความรู้และทักษะในสาขาวิชาชีพ พืชศาสตร์เพื่อสร้างหรือพัฒนางาน
ด้วยกระบวนการทดลอง สำรวจ ประดิษฐ์คิดค้น หรือการปฏิบัติงานเชิงระบบ การเลือกประเด็นและกำหนดหัวข้อ
โครงงาน การศึกษาค้นคว้าข้อมูลและเอกสารที่เกี่ยวข้อง การจัดทำข้อเสนอโครงงาน การวางแผนและดำเนินโครงงาน 
การเก็บรวบรวม วิเคราะห์และแปลผลข้อมูล การแก้ไขปัญหาและประเมินผลการดำเนินงาน การจัดทำรายงานและ
นำเสนอผลงาน โดยดำเนินการเป็นรายบุคคลหรือกลุ่มตามลักษณะของงานให้แล้วเสร็จตามระยะเวลาที่กำหนด
