# 30905*1128 การฝึกวิชาชีพพืชศาสตร์

> [!source] แหล่งข้อมูล
> PDF หน้า 110

30905*1128 การฝึกวิชาชีพพืชศาสตร์             0-12-4 
Plant Science Professional Practice    
อ้างอิงมาตรฐาน 
 -  
ผลลัพธ์การเรียนรู้ระดับรายวิชา  
1. อธิบายลักษณะงาน ขั้นตอนการปฏิบัติงาน  และข้อกำหนดที่เกี่ยวข้องกับงานที่ได้รับมอบหมายในสถาน
ประกอบการ 
2. เตรียมและใช้เครื่องมือ  อุปกรณ์ และเทคโนโลยีที่เกี่ยวข้องกับงานที่ได้รับมอบหมายอย่างถูกต้องและ
ปลอดภัย 
3. ปฏิบัติงานด้านพืชศาสตร์ตามหน้าที่และขอบเขตงานที่ได้รับมอบหมายตามขั้นตอนและข้อกำหนดของ
สถานประกอบการ 
4. วิเคราะห์ปัญหาที่เกิดจากการปฏิบัติงานและเลือกแนวทางแก้ไขหรือปรับปรุงงานให้เหมาะสมกับ
สถานการณ์ 
5. บันทึกและประเมินผลการปฏิบัติงานโดยใช้ข้อมูลและเทคโนโลยีที่เหมาะสม 
6. จัดทำรายงานและนำเสนอผลการฝึกงาน  พร้อมแสดงความรับผิดชอบ  มีวินัย ปฏิบัติงานอย่างปลอดภัย  
และทำงานร่วมกับผู้อื่น 
จุดประสงค์รายวิชา  เพื่อให้  
1. เข้าใจขั้นตอน กระบวนการ และการจัดการงานพืชศาสตร์ในสถานประกอบการ 
2. สามารถบูรณาการความรู้และทักษะด้านพืชศาสตร์ในการปฏิบัติงานตามหน้าที่และขอบเขตงานที่ได้รับ
มอบหมาย 
3. สามารถใช้เครื่องมือ  อุปกรณ์ ข้อมูล และเทคโนโลยีที่เกี่ยวข้องกับการปฏิบัติงาน  รวมทั้งวิเคราะห์และ
แก้ไขปัญหาหน้างานเบื้องต้น 
4. สามารถบันทึก ประเมิน และรายงานผลการปฏิบัติงานอย่างเป็นระบบ 
5. มีเจตคติที่ดีต่อวิชาชีพ ปฏิบัติงานด้วยความรับผิดชอบ มีวินัย จรรยาบรรณ ความปลอดภัย และสามารถ
ทำงานร่วมกับผู้อื่น 
สมรรถนะรายวิชา 
1. ปฏิบัติงานด้านพืชศาสตร์ตามหน้าที่และขอบเขตงานที่ได้รับมอบหมาย  โดยปฏิบัติตามขั้นตอน  ความ
ปลอดภัย และข้อกำหนดของสถานประกอบการ 
2. ประยุกต์ใช้ความรู้  ทักษะ เครื่องมือ และเทคโนโลยีที่เกี่ยวข้องในการปฏิบัติงานและการจัดการงานพืช
ศาสตร์ในสถานประกอบการ 
3. วิเคราะห์ปัญหาจากการปฏิบัติงานและเลือกแนวทางแก้ไขหรือปรับปรุงงานให้เหมาะสมกับสถานการณ์
และขอบเขตความรับผิดชอบ 
4. จัดการข้อมูล บันทึก ประเมิน และรายงานผลการปฏิบัติงานอย่างเป็นระบบ  พร้อมแสดงพฤติกรรมการ
ทำงานที่รับผิดชอบและทำงานร่วมกับผู้อื่น 
คำอธิบายรายวิชา  
ปฏิบัติงานที่สอดคล้องกับสาขาวิชาพืชศาสตร์ในสถานประกอบการ  สถานประกอบอาชีพอิสระ  หรือแหล่ง
วิทยาการอย่างต่อเนื่องตลอดภาคการศึกษา ไม่น้อยกว่า 320 ชั่วโมง โดยบูรณาการความรู้และทักษะด้านพืชศาสตร์ใน
การปฏิบัติงานตามหน้าที่และขอบเขตงานที่ได้รับมอบหมาย การใช้เครื่องมือ อุปกรณ์ ข้อมูลและเทคโนโลยีที่เกี่ยวข้อง
