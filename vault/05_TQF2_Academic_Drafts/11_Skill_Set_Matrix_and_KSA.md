ตารางแสดงผลลัพธ์การเรียนรู้ระดับหลักสูตร (PLOs)  กับ Knowledge/ Attitude/ Skill 
 
ผลลัพธ์การเรียนรู้ระดับหลักสูตร (PLOs) Knowledge (Cognitive) Skill (Psychomotor) Attitude (Affective) 
PLO1 ปฏิบัติงานด้านพืชศาสตร์ตามมาตรฐานวิชาชีพ 
โดยยึดมั่นคุณธรรม จริยธรรม จรรยาบรรณวิชาชีพ ความ
ปลอดภัยในการปฏิบัติงาน และความรับผิดชอบต่อสังคม
และสิ่งแวดล้อม 
K3 – ประยุกต์ใช้ 
นำความรู้เกี่ยวกับมาตรฐานวิชาชีพ 
ความปลอดภัย จริยธรรม และ
สิ่งแวดล้อมไปใช้ในการปฏิบัติงานด้าน
พืชศาสตร์ 
S4 – ปฏิบัติได้ถูกต้องและปรับ
ประยุกต์ 
ปฏิบัติงานด้านพืชศาสตร์ได้ถูกต้องตาม
มาตรฐาน และปรับวิธีปฏิบัติให้
เหมาะสมกับงาน 
A5 – ยึดถือเป็นคุณลักษณะประจำตน  
แสดงคุณธรรม จริยธรรม จรรยาบรรณ 
ความรับผิดชอบ และพฤติกรรมด้าน
ความปลอดภัยอย่างสม่ำเสมอ 
PLO2 ใช้ความรู้และหลักการด้านพืชศาสตร์ในการผลิต
พืช การจัดการแปลงผลิต และการจัดการศัตรูพืชได้ตาม
มาตรฐานวิชาชีพ 
K3 – ประยุกต์ใช้ 
นำความรู้และหลักการด้านพืชศาสตร์ไป
ใช้ในการผลิตพืช จัดการแปลง และ
จัดการศัตรูพืช 
S4 – ปฏิบัติได้ถูกต้องและปรับ
ประยุกต์ 
ปฏิบัติงานผลิตพืชและจัดการแปลงได้
ถูกต้องตามมาตรฐาน พร้อมปรับวิธี
ปฏิบัติตามสภาพงาน 
– 
ไม่ได้กำหนดผลลัพธ์ด้านเจตคติเป็น
สาระหลักโดยตรง โดยเจตคติทาง
วิชาชีพครอบคลุมอยู่ใน PLO1 
PLO3 เลือกใช้เครื่องมือ เทคโนโลยีดิจิทัล และข้อมูล เพื่อ
สนับสนุนการผลิตพืชและการจัดการฟาร์มได้อย่าง
เหมาะสมกับลักษณะงานและพื้นที่ 
K4 – วิเคราะห์  
วิเคราะห์ลักษณะงาน สภาพพื้นที่ และ
ข้อมูลที่เกี่ยวข้อง เพื่อเลือกเครื่องมือ
หรือเทคโนโลยีที่เหมาะสม 
S4 – ปฏิบัติได้ถูกต้องและปรับ
ประยุกต์ 
ใช้เครื่องมือ เทคโนโลยีดิจิทัล และ
ระบบข้อมูลได้อย่างถูกต้อง พร้อมปรับ
ใช้ให้เหมาะกับงานและพื้นที่ 
– 
ไม่ได้มุ่งประเมินเจตคติเป็นผลลัพธ์หลัก 
PLO4 วิเคราะห์ปัญหาและเลือกแนวทางแก้ไขในการผลิต
พืชโดยใช้หลักวิชาการ เทคโนโลยี และข้อมูลที่เหมาะสม
กับบริบทของชุมชนหรือสถานประกอบการ 
K4 – วิเคราะห์  
จำแนกองค์ประกอบของปัญหา 
วิเคราะห์สาเหตุและข้อมูล แล้วเลือก
แนวทางแก้ไขที่เหมาะสมกับบริบท 
– 
ไม่ได้กำหนดการปฏิบัติทางกายเป็น
ผลลัพธ์หลัก 
– 
ไม่ได้กำหนดผลลัพธ์ด้านเจตคติไว้
โดยตรง 
PLO5 วางแผนและดำเนินงานด้านการผลิตพืชหรือธุรกิจ
เกษตรขนาดย่อมโดยคำนึงถึงต้นทุน ตลาด และการใช้
ทรัพยากรอย่างเหมาะสม 
K6 – สร้างสรรค์  
บูรณาการความรู้และข้อมูลหลายด้าน
เพื่อสร้างแผนการผลิตพืชหรือแผนธุรกิจ
เกษตรขนาดย่อม 
S5 – บูรณาการทักษะในการทำงาน
จริง 
ประสานทักษะด้านการผลิต การจัดการ 
และธุรกิจเพื่อดำเนินงานตามแผน 
พร้อมปรับปรุงการทำงาน 
A3 – เห็นคุณ ่า  
แสดงความรับผิดชอบและเห็น
ความสำคัญของการดำเนินงานอย่างเป็น
ระบบ มีประสิทธิภาพ และคุ้มค่าต่อ
ทรัพยากร

PLO6 สื่อสาร ประสานงาน และปฏิบัติงานร่วมกับชุมชน 
สถานประกอบการ และเครือข่ายวิชาชีพโดยสอดคล้องกับ
วัฒนธรรมองค์กรและบริบทชุมชน 
K3 – ประยุกต์ใช้ 
นำหลักการสื่อสาร การประสานงาน 
และการทำงานร่วมกับผู้อื่นไปใช้ให้
เหมาะกับบุคคลและสถานการณ์ 
S5 – บูรณาการทักษะในการทำงาน
จริง 
บูรณาการทักษะการสื่อสาร การ
ประสานงาน และการทำงานเป็นทีมกับ
ผู้เกี่ยวข้องหลายฝ่าย 
A4 – จัดระบบคุณ ่า  
ปรับค่านิยมและพฤติกรรมของตนให้
สอดคล้องกับวัฒนธรรมองค์กร ความ
แตกต่างของบุคคล และบริบทชุมชน 
 
หมายเหตุ: K = Knowledge, S = Skill, A = Attitude 
ระดับการเรียนรู้ตามทฤษฎีของบลูม (Bloom’s Taxonomy) 
ระดับ K ความหมาย  ระดับ S ความหมาย  ระดับ A ความหมาย  
K1 = Remembering (จำได้) S1 = Imitating (รับรู้) A1 = Receiving (รับรู้) 
K2 = Understanding (เข้าใจ) S2 = Manipulating (ทำตามได้) A2 = Responding (ตอบสนอง) 
K3 = Applying (ประยุกต์ได้) S3 = Precising (ทำถูกต้อง หาความถูกต้องได้ A3 = Valuating (เห็นคุณค่า) 
K4 = Analysis (วิเคราะห์ได้) S4 = Articulating (ทำได้อย่างคล่องแคล่ว) A4 = Organizing (จัดการ) 
K5 = Evaluating (ประเมินได้) S5 = Naturalizing (ทำได้เป็นธรรมชาติ) A5 = Characterizing (บุคลิก นิสัย) 
K6 = Creating (คิดสร้างสรรค์)
