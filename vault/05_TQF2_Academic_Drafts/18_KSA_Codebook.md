# KSA Codebook

## Knowledge (Cognitive)

| ระดับ | ความหมาย |
|---|---|
| K1 | Remembering - จำได้ |
| K2 | Understanding - เข้าใจ |
| K3 | Applying - ประยุกต์ได้ |
| K4 | Analysis - วิเคราะห์ได้ |
| K5 | Evaluating - ประเมินได้ |
| K6 | Creating - คิดสร้างสรรค์ |

## Skill (Psychomotor)

| ระดับ | ความหมาย |
|---|---|
| S1 | Imitating - รับรู้ |
| S2 | Manipulating - ทำตามได้ |
| S3 | Precising - ทำถูกต้องและหาความถูกต้องได้ |
| S4 | Articulating - ทำได้อย่างคล่องแคล่ว |
| S5 | Naturalizing - ทำได้เป็นธรรมชาติและบูรณาการทักษะในงานจริง |

## Attitude (Affective)

| ระดับ | ความหมาย |
|---|---|
| A1 | Receiving - รับรู้ |
| A2 | Responding - ตอบสนอง |
| A3 | Valuating - เห็นคุณค่า |
| A4 | Organizing - จัดระบบคุณค่า |
| A5 | Characterizing - ยึดถือเป็นบุคลิกหรือนิสัยประจำตน |
